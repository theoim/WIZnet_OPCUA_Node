## 1. 24시간 시험 — W6300-EVB-Pico2

2026-11-09 ~ 11-10. 보안 빌드(커밋 5c87e96), 클라이언트 2개(Basic256Sha256 Sign & Encrypt 1개,
None 1개). 도구: `tools/opcua_soak_test.py`.

| 부하 | 값 |
|---|---|
| UART 입력 | 초당 10줄, 24시간 |
| 정상 접속·해제 | 120초마다 |
| 세션을 닫지 않고 클라이언트 강제 종료 | 600초마다 |
| 링크 장애 (케이블 20초 끊김) | 2시간마다 |

| 확인 항목 | 결과 |
|---|---|
| 재부팅 | **0** |
| UART 줄 해석 | **864,002 / 864,002**, 오류 0 |
| 클라이언트가 본 값 | 스냅샷 169,416개, 불량 0, 중복·순서 뒤바뀜 없음 |
| 예기치 않은 클라이언트 끊김 | **0** |
| 정상 접속 | 577 / 577 |
| 강제 종료된 세션 회수 | 131 / 131, 30~36초 안 |
| 링크 장애 복구 | 12 / 12, 45.3초 안 |
| 최저 남은 힙 | 299,008 B |
| 남은 힙, 시작 → 끝 | 333,504 → 327,740 B (−5,764 B) |

**힙 감소는 누수가 아니라 상한이 있는 큐입니다.**
- **무엇:** 링크 장애 1회마다 남은 힙이 약 500 B씩 줄었습니다.
- **왜:** 링크가 끊긴 동안 보낸 응답은 클라이언트의 확인을 받지 못해 세션의 재전송 큐에 남습니다.
  큐는 세션당 최대 16항목입니다. 링크 장애만 반복한 70분 후속 시험(3분 간격 22회)에서 처음 15회는
  같은 비율로 줄었고, 큐가 가득 찬 뒤로는 서버가 "retransmission queue overflow"를 기록하고 가장
  오래된 항목을 버리면서 더 줄지 않았습니다. 세션이 끝나면 메모리가 돌아옵니다.
- **어떻게:** 따로 조치할 필요는 없습니다. 링크가 자주 끊기는 환경이라면 세션당 최대 약 12 KB(RP2040은 4 KB)를
  재전송 큐 몫으로 잡아 두면 됩니다. 한도는 CMake 옵션 `OPCUA_RETRANSMIT_MAX_HEAP`입니다.

## 2. 보안 핸드셰이크 영향 — W6300-EVB-Pico2

2026-11-11. 보안 빌드, Basic256Sha256. 도구: `tools/opcua_handshake_impact.py`.

| 측정 | 값 |
|---|---|
| 보안 채널 열기(OPN) 1회 | 1,233 ms, 그중 개인키 연산 1,156 ms |
| 그동안 다른 세션 Read 최대 대기 | 1.2초 (평소 p99 6 ms) |
| 다른 세션 알림 최대 공백 | 1.33초 (평소 p99 104 ms) |
| 클라이언트 2개 동시 접속 | 2.4초 / 2.5초 |
| 핸드셰이크 중 보드의 TCP ACK 지연 | p99 0.9 ms 이하 |

TCP 연결은 끊기지 않습니다. MCU가 RSA 계산으로 바쁜 동안에도 W6300 칩이 TCP 응답(ACK)을 직접
보내기 때문입니다. 클라이언트의 watchdog을 1초로 두면 핸드셰이크 중 한 번 타임아웃이 날 수 있고,
5초에서는 나지 않았습니다. 그래서 클라이언트 타임아웃은 5초 이상을 권장합니다.

## 3. MCU별 RSA·ECC 비용

두 부품 모두 같은 Mbed TLS 빌드입니다. 개발 저장소의 벤치마크 빌드로 측정했고, 이 저장소에는 포함하지 않았습니다.

| | RSA-2048 핸드셰이크 (Basic256Sha256) | ECC P-256 핸드셰이크 |
|---|---|---|
| RP2040 @200 MHz (오버클럭, 정격 133 MHz) | **5,050 ms** | 384 ms |
| RP2350 @150 MHz (기본) | **1,229 ms** | 264 ms |

RP2350의 Cortex-M33에는 32비트 곱셈 결과를 64비트로 한 번에 내는 명령이 있고, RP2040의 Cortex-M0+에는
없습니다. ECC는 두 부품 모두에서 더 싸지만, 일반 OPC UA 클라이언트는 Basic256Sha256으로 접속하므로
실제로 중요한 것은 RSA 수치입니다.
